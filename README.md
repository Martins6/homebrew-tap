# Martins6 Homebrew Tap

Homebrew tap for [Simple Beads](https://github.com/Martins6/simple-beads).

After the first stable release is published, install it with:

```sh
brew install Martins6/tap/sb
```

`Formula/sb.rb` is generated from the immutable source archive and SHA-256
checksum for each stable release tag by the Simple Beads release workflow.
